# awesome-design-md

## Description
A Claude Skill to browse and reference awesome design markdown resources.

## Usage
- After installing this Skill in Claude, you can ask Claude to provide design references from the markdown content in `design-md/`.
- The Skill organizes and summarizes design resources for quick access.

## Files
- `design-md/` - Main markdown content with design references.
- `README.md` - Project overview.
- `LICENSE` - MIT license.

## Notes
- Ensure this file (`SKILL.md`) is in the root of the ZIP you upload.
- Claude will use this file to recognize the folder as a Skill.
